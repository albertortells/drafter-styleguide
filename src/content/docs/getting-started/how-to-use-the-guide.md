Aquesta guia recull els components de la interfície de Drafter, tal com els ha dissenyat l'equip d'UX/UI. La idea és que els utilitzis tal qual, perquè totes les pantalles es vegin i es comportin igual.

## Com incloure un component en una pantalla

1. Busca el component al menú lateral o amb el cercador.
2. Llegeix quan s'ha d'utilitzar (i quan no) a la descripció del component.
3. Copia'n el codi **HTML**, **CSS** i **JS** amb el botó de copiar de cada bloc.
4. Enganxa'l a la part de l'aplicació on el necessitis.
